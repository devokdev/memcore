Core Engine

Designed for real-world agent memory.

Local-first SQLite storage with code-grounded verification and zero loss on critical rules.

01 / PERSISTENCE
Cross-Session Retention
Preserves project decisions, architecture contracts, and security rules across separate coding sessions and IDE restarts.
02 / RISK-AWARE GC
MemGC Garbage Collection
Prunes stale debug notes and dead port commands while preserving 100% of protected security constraints.
03 / AST GROUNDED
Code Verification
Parses local source code trees to verify symbol existence before returning memories to the agent to avoid hallucinations.
04 / OPTIMIZATION
Token Budgeting
Dynamically knapsack-packs only the most task-relevant memories into strict token limits (saving up to ~90% tokens).
05 / PRIVACY
100% Local-First
Runs entirely on 127.0.0.1 on your machine. Zero code or prompt bytes leave localhost.
